## 2. AST分析流程

```
代码字符串: "result = x * 2"
     │
     ▼
┌─────────────┐
│ ast.parse() │ 解析代码生成抽象语法树
└──────┬──────┘
       │
       ▼
AST树结构:
    Module
      └── Assign
            ├── targets: [Name(id='result', ctx=Store)]
            └── value: BinOp
                  ├── left: Name(id='x', ctx=Load)
                  ├── op: Mult
                  └── right: Constant(value=2)
       │
       ▼
┌────────────────────┐
│ ast.NodeVisitor    │ 遍历AST节点
└─────────┬──────────┘
          │
          ├──> 发现 Name(id='result', ctx=Store)
          │    → 记录: 定义变量 'result'
          │
          └──> 发现 Name(id='x', ctx=Load)
               → 记录: 使用变量 'x'
          │
          ▼
结果: {'required': ['x'], 'produced': ['result']}
```

## 3. 依赖图与拓扑排序

### 3.1 原始模块

```
模块A: result = x * 2
模块B: y = result + 10
模块C: final = y ** 2
```

### 3.2 构建依赖图

```
分析依赖关系:
- 模块A 需要: [x]          产生: [result]
- 模块B 需要: [result]     产生: [y]
- 模块C 需要: [y]          产生: [final]

依赖图:
    x未定义
       │
       ▼
   ┌────────┐
   │ 模块A  │ 产生 result
   └───┬────┘
       │ result
       ▼
   ┌────────┐
   │ 模块B  │ 产生 y
   └───┬────┘
       │ y
       ▼
   ┌────────┐
   │ 模块C  │ 产生 final
   └────────┘
```

### 3.3 Kahn算法排序

```
步骤1: 计算入度
    模块A: 入度 = 0 (没有依赖)
    模块B: 入度 = 1 (依赖模块A)
    模块C: 入度 = 1 (依赖模块B)

步骤2: 找出入度为0的节点
    队列 = [模块A]
    结果 = []

步骤3: 处理队列
    取出模块A:
        - 加入结果: [模块A]
        - 更新模块B入度: 1 → 0
        - 模块B入度为0，加入队列
    
    取出模块B:
        - 加入结果: [模块A, 模块B]
        - 更新模块C入度: 1 → 0
        - 模块C入度为0，加入队列
    
    取出模块C:
        - 加入结果: [模块A, 模块B, 模块C]
    
    队列为空，完成

步骤4: 添加初始化
    检测到x未定义
    最终顺序: [初始化x, 模块A, 模块B, 模块C]
```

## 6. 核心算法伪代码

### 6.1 依赖分析

```python
function analyze_dependencies(code):
    tree = AST.parse(code)
    required = set()
    produced = set()
    
    for node in tree.walk():
        if node is Name:
            if node.context is Store:
                produced.add(node.id)
            elif node.context is Load:
                if node.id not in local_vars:
                    required.add(node.id)
    
    return {required, produced}
```

### 6.2 拓扑排序

```python
function topological_sort(modules):
    # 计算入度
    in_degree = calculate_in_degree(modules)
    
    # 找出入度为0的节点
    queue = [m for m in modules if in_degree[m] == 0]
    result = []
    
    while queue is not empty:
        node = queue.pop()
        result.append(node)
        
        # 更新依赖该节点的其他节点
        for dependent in node.dependents:
            in_degree[dependent] -= 1
            if in_degree[dependent] == 0:
                queue.append(dependent)
    
    if len(result) != len(modules):
        raise "循环依赖错误"
    
    return result
```

### 6.3 类型推断

```python
function infer_type(var_name):
    patterns = {
        '_list$': 'list',
        '_dict$': 'dict',
        '^is_': 'bool',
        '^num_': 'int',
        '_file$': 'str'
    }
    
    for pattern, type in patterns:
        if var_name matches pattern:
            return type
    
    return 'unknown'
```
